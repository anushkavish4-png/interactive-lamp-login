# Interactive Lamp Login Form

### Light up the lamp. Log in. Enjoy the experience.

A creative and interactive login page designed to turn a simple login form into a more engaging experience. It features a cute animated lamp, smooth GSAP animations, responsive UI, form validation, and dynamic login notifications with changing colors and emojis.

Built with HTML, CSS, JavaScript, and GSAP to explore interactive frontend design and animations.

## Features

- Interactive lamp ON/OFF animation
- Smooth GSAP animations
- Responsive design
- Login form validation
- Dynamic success/error notifications
- Random colors and emojis
- Clean and modern UI

## Tech Stack

**HTML5 • CSS3 • JavaScript • GSAP**
